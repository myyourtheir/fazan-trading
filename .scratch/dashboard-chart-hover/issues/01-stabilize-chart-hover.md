# 01: Убрать скачок графика при наведении

Status: done

## Объём

Устранить смещение графика свечей на dashboard при наведении и выходе указателя. Не менять данные, торговую логику, график бэктеста или настройки шкал без воспроизводимой причины.

## Решение

Перенести сводку из пространства над графиком под область построения, оставив её в обычном потоке. При переходе с последней свечи на историческую поля сводки могут занимать разное число строк; перенос под область построения сохраняет читаемость без фиксированной высоты и не сдвигает холст. Настройки шкал не меняются.

## Критерии приёмки

- [x] Холст не меняет положение или размер при наведении на историческую свечу и выходе указателя, в том числе на узком экране при изменении высоты сводки.
- [x] Сводка по-прежнему показывает выбранную свечу при наведении и последнюю при выходе; перекрестие, масштабирование и живые обновления работают как раньше.
- [x] Регрессионный Playwright-тест падает без исправления и проходит с ним.

## Зависимости

Существующий график и тестовые моки из [serfing/04](../../serfing/issues/04-live-candles-and-ema.md). Новых зависимостей нет.

## Проверка

В `frontend/` под Node.js 24+: `npm ci`, `npm run lint:architecture`, `npm run build`, `npm test`. Отдельно запустить регрессионный тест без исправления и с ним. Не изменять существующую правку в `DateRangePicker.tsx`.

## Comments

Chromium при ширине 360 px воспроизвёл скачок: при наведении верх холста сместился с 254 до 314 px. После переноса сводки регрессионный тест проходит. Установка, архитектурный линтер и сборка прошли. В рабочей копии полный прогон дал 26 успешных тестов и одну ошибку в сценарии календаря бэктеста. В чистой копии `HEAD` с патчем только для dashboard прошли все 27 тестов.

По замечанию ревью добавлена явная проверка, что сводка исторической свечи выше сводки последней свечи. Целевой тест прошёл, повторное ревью — без замечаний. На финальном патче в чистой копии прошли сборка, архитектурный линтер и все 27 тестов.
