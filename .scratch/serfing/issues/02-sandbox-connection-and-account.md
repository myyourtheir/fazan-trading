# 02: Подключение к песочнице и выбор счёта

Status: done

**Что сделать:** Дать владельцу возможность подключить песочницу Т‑Инвестиций из панели и выбрать один выделенный виртуальный счёт.

**Блокируется:** [01 — Локальный запуск и вход владельца](01-local-launch-and-login.md).

## Критерии приёмки

- [x] Владелец вводит токен и видит результат проверки подключения. Ошибка токена или связи понятна и не раскрывает секрет.
- [x] Используется официальный SDK `invest-js` и только endpoint песочницы. Режима реальной торговли нет.
- [x] Токен зашифрован в PostgreSQL, ключ хранится вне базы. Токен не возвращается браузеру и не записывается в журнал.
- [x] Интерфейс позволяет выбрать существующий счёт песочницы либо создать и пополнить новый. Выбранный счёт и сохранённое подключение восстанавливаются после перезапуска.
- [x] Автоматические проверки покрывают сохранение и недоступность токена в открытом виде, успешное подключение и ошибку подключения. Сценарий с действующим sandbox-токеном можно проверить отдельно.
