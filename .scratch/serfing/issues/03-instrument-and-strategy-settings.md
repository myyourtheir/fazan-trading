# 03: Выбор фьючерса и параметры стратегии

Status: ready-for-agent

**Что сделать:** Дать владельцу возможность настроить один фьючерс, период EMA и объём позиции на выбранном счёте песочницы.

**Блокируется:** [02 — Подключение к песочнице и выбор счёта](02-sandbox-connection-and-account.md).

## Критерии приёмки

- [ ] Поиск по названию или тикеру показывает только фьючерсы, доступные для торговли через API. Совпадающие тикеры представлены отдельными результатами с данными для различения.
- [ ] `IMOEXF` и EMA55 предложены как исходные параметры. Если найдено несколько подходящих контрактов, инструмент выбирается явно. Объём позиции задаёт владелец.
- [ ] Сервер проверяет инструмент, период EMA и положительный целый объём в лотах. Сохранённый инструмент определяется по уникальному ID брокера, а не только по тикеру.
- [ ] Сохраняется один набор активных настроек; после перезапуска панель показывает те же значения.
- [ ] Проверки покрывают неоднозначный тикер, отклонение неверных параметров и восстановление настроек.
