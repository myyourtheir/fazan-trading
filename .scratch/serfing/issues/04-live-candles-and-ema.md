# 04: Живой график свечей и EMA

Status: done

**Что сделать:** Показать владельцу часовые свечи и EMA выбранного фьючерса, включая живое обновление текущей свечи. Этот сценарий не выставляет заявки.

**Блокируется:** [03 — Выбор фьючерса и параметры стратегии](03-instrument-and-strategy-settings.md).

## Критерии приёмки

- [x] Фронтенд через REST API и RTK Query загружает исторические часовые свечи и подтверждённые значения EMA от `GetTechAnalysis` за соответствующие свечи.
- [x] Живые обновления свечей, EMA и состояния потока приходят с бэкенда через авторизованный WebSocket и обновляют кэш RTK Query. Предварительная EMA явно отличается от подтверждённой; отсутствие подтверждения не подменяется приблизительным значением.
- [x] Повторные обновления того же часового интервала не дублируют свечу. Состояние потока отображается независимо от состояния робота.
- [x] Проверки с подменным брокером покрывают привязку EMA к той же свече, обновление текущей свечи и отсутствие дубликатов. Контракт временных меток и поток можно проверить отдельно в песочнице.
