# 07: Остановка, ручное закрытие и блокировка настроек

Status: done

**Что сделать:** Разделить остановку робота и закрытие позиции; не допускать смену торговых настроек при работающем роботе или открытой позиции.

**Блокируется:** [05 — Первый вход и журнал исполнений](05-first-entry-and-execution-history.md).

## Критерии приёмки

- [x] «Стоп» прекращает отправку новых заявок, но не закрывает позицию и не отменяет уже отправленную заявку.
- [x] На остановленном роботе отдельная команда с подтверждением закрывает фактическую позицию одной встречной рыночной заявкой. При нулевой позиции заявки нет; завершение подтверждается сверкой.
- [x] Ручное закрытие отображается в журнале как отдельное действие, без привязки к пересечению EMA.
- [x] Смену счёта, инструмента, периода EMA и объёма разрешает сервер только после остановки и подтверждения нулевой позиции. Интерфейс объясняет причину блокировки.
- [x] Тесты проверяют остановку с открытой позицией, подтверждение ручного закрытия и запрет изменений через серверный интерфейс.
