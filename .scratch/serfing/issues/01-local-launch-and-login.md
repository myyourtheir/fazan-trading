# 01: Локальный запуск и вход владельца

Status: done

**Что сделать:** Дать владельцу возможность запустить приложение и PostgreSQL через Docker Compose и войти в панель управления роботом по паролю.

**Блокируется:** Нет — можно начать сразу.

## Критерии приёмки

- [x] Бэкенд и фронтенд находятся в отдельных каталогах `backend/` и `frontend/`, имеют свои зависимости, конфигурацию окружения и команды запуска и сборки. Docker Compose запускает оба приложения и PostgreSQL; миграции применяются при первом запуске и не ломают повторный запуск.
- [x] Владелец входит по заданному паролю, видит панель и может выйти. Регистрации и ролей нет.
- [x] Фронтенд общается с бэкендом через REST API: запросы и мутации управляются RTK Query, глобальное клиентское состояние — Redux Toolkit. Секреты бэкенда не доступны сборке фронтенда.
- [x] Неверный пароль не даёт доступа; защищённые серверные запросы без действующей сессии отклоняются.
- [x] Автоматическая проверка покрывает вход, отказ и недоступность панели без сессии.
