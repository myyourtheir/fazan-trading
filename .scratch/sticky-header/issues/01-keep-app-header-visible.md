# 01: Закрепить общий хедер

Status: done

## Объём

Закрепить общий хедер `AppShell` сверху при вертикальной прокрутке страницы. Не менять отдельные заголовки экранов, навигацию и API.

## Решение

Использовать Tailwind `sticky top-0`, сохранив хедер в потоке: контент начинается под ним без фиксированного отступа, даже если хедер переносится на узком экране. Оставить непрозрачный фон из темы; слой хедера должен быть выше контента, но ниже портальных меню и диалогов.

## Критерии приёмки

- [x] При прокрутке контент смещается, а общий хедер остаётся у верхнего края окна.
- [x] До прокрутки хедер не перекрывает начало контента; на прокрученной странице элементы управления хедера доступны.
- [x] Playwright проверяет реальную прокрутку и положение хедера относительно окна.

## Зависимости

Нет; используются текущая оболочка приложения, Tailwind и Playwright.

## Проверка

В `frontend/` под Node.js 24+: `npm ci`, `npm run lint:architecture`, `npm run build`, `npm test`. Проверить, что тест на закрепление не проходит без изменения хедера.

## Comments

Установка, архитектурный линтер, сборка и все 26 браузерных тестов прошли. Без закрепления новый тест падает: после прокрутки координата хедера равна −400 px. Сборка выводит предупреждение Vite о размере чанка.

Независимое ревью прошло без замечаний. Дополнительная проверка сборки в Chromium при ширине 280 px подтвердила, что двухстрочный хедер закреплён, контент начинается под ним, а меню профиля открывается после прокрутки.
