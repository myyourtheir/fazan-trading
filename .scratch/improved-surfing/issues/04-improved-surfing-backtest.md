# 04: Добавить полный бэктест стратегий

**Что сделать:** Дать пользователю возможность запускать сопоставимый бэктест обеих стратегий с историческими данными и настраиваемыми условиями исполнения, не меняя сохранённые профили.

**Блокируется:** 01 — Подтвердить техническую реализуемость; 02 — Добавить выбор стратегий и управление профилями; 03 — Реализовать «Улучшенный серфинг» в роботе.

Status: ready-for-agent

- [ ] Страница бэктеста позволяет выбрать стратегию; переход с дашборда и прямое открытие выбирают стратегию и последний сохранённый профиль дашборда.
- [ ] Параметры стратегии можно изменять только для симуляции; при переключении стратегии сохраняются даты, комиссия и проскальзывание, а настройки пользователя и выбор на дашборде не меняются.
- [ ] Форма включает начальные свободные деньги (по умолчанию 100 000 ₽), диапазон дат, комиссию (процент номинала), проскальзывание (неблагоприятное число шагов цены); нулевые издержки видны явно.
- [ ] Бэктест использует историческую брокерскую EMA и минутные свечи для моделирования стопов, а также те же правила сигналов, размера позиции, доборов, стопов, гэпов, разворотов и календаря, что и робот. Тест публичного прогона бэктеста сравнивает торговые решения с публичным поведением Robot на одинаковых событиях и исполнениях.
- [ ] Сигнал по закрытию исполняется по первой доступной цене после сигнала в той же сессии; гэп — по открытию; внутрисвечный стоп — по уровню при касании или по открытию при перескоке уровня. Комиссия и проскальзывание применяются к каждому исполнению; разворот моделируется отдельными исполнениями выхода и входа.
- [ ] История включительна по Москве; предшествующие свечи используются только для прогрева. Недостающие свечи, EMA, расписание или обоснованная оценка обеспечения приводят к понятному отказу без молчаливого сокращения диапазона или упрощения стопа.
- [ ] Отчёт показывает доходность в деньгах и процентах после комиссии, максимальную просадку, суммарную комиссию, график стоимости счёта, журнал исполнений, отдельные реализованный/нереализованный результаты и открытую позицию на конец периода без фиктивного закрытия.
- [ ] Рядом с результатом показаны модель исполнения и её ограничения; результаты прогонов не сохраняются на сервере.
