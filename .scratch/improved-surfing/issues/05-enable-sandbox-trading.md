# 05: Допустить торговый режим в песочнице

**Что сделать:** Разрешить явный запуск «Улучшенного серфинга» в песочнице только после подтверждения безопасной работы нативных стопов, сверки и восстановления.

**Блокируется:** 01 — Подтвердить техническую реализуемость (только подтверждением безопасной работы стопов или контрактом брокера; неподтверждённая история не блокирует торговый допуск); 03 — Реализовать «Улучшенный серфинг» в роботе.

Status: ready-for-agent

- [ ] Для допуска используются результаты проверки возможностей стопов из 01: сохранение при отключении, сверка после срабатывания и отсутствие двойного выхода при неатомарной замене уровня/объёма, либо необходимое подтверждение контракта брокером. Непрерывная защита при замене не требуется. Повторное исследование API не требуется.
- [ ] Фактический брокерский адаптер и собранное приложение допускают явный запуск новой стратегии только при успешном выполнении критериев допуска и проверенной безопасной сверке и восстановлении поведения из 03; при провале запуск остаётся заблокированным с объяснением причины.
- [ ] Допуск новой стратегии не блокирует её бэктест и не меняет доступность или поведение `Surfing`.
- [ ] Проверка не использует реальные сделки за деньги; автоматические проверки не требуют брокерского токена.
