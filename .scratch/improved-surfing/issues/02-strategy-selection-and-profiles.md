# 02: Добавить выбор стратегий и управление профилями

**Что сделать:** Дать пользователю возможность выбирать `Surfing` или «Улучшенный серфинг», сохранять отдельные профили и безопасно менять выбранный торговый счёт, не теряя совместимость существующего `Surfing`.

**Блокируется:** Ничем (можно начать сразу).

**Статус:** ready-for-agent

- [ ] Дашборд позволяет выбрать одну из двух стратегий; выбор и отдельные настройки обеих стратегий сохраняются за учётной записью приложения и переживают перезапуск без автоматического запуска робота.
- [ ] Профиль «Улучшенного серфинга» поддерживает инструмент из существующего поиска, таймфрейм 5/15/30/60 минут, EMA и ATR, множитель стопа, шаг и лимит доборов, а также настройку торговли по выходным с согласованными значениями по умолчанию.
- [ ] Старые настройки `Surfing` сохраняются без потерь и однократно связываются с явно подтверждённой учётной записью, если владелец не может быть доказан; старый API без вида стратегии продолжает означать `Surfing`.
- [ ] Позиции, заявки, стопы и журнал остаются привязаны к выбранному торговому счёту; смена счёта запрещена при работающем роботе, позиции, незавершённых заявках или стопах и не переносит торговое состояние.
- [ ] Сервер запрещает менять стратегию и её настройки, если робот работает, позиция не нулевая или есть заявки с невыясненным статусом; интерфейс показывает причину и не позволяет обходить ограничение.
