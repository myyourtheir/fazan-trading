# 04: Запускать бэктест из черновика настроек

Status: done

**Что сделать:** Дать владельцу проверить значения из формы стратегии до сохранения и не спутать последний успешный отчёт с результатом по уже изменённым параметрам.

**Блокируется:** [02 — Получить первый отчёт по стратегии](02-run-strategy-backtest.md).

**Спецификация:** [Бэктест стратегии «Сёрфинг»](../spec.md).

## Критерии приёмки

- [x] Кнопка «Бэктест» под кнопкой «Сохранить настройки» в карточке на `/dashboard` открывает `/backtest` со снимком текущих значений формы, включая несохранённые правки. Переход не сохраняет настройки, не запускает прогон и не передаёт черновик в URL.
- [x] Кнопка не наследует ограничения сохранения, связанные с состоянием робота и счёта. Поля бэктеста можно менять независимо от настроек робота.
- [x] Прямой вход и обновление страницы подставляют последние сохранённые параметры, если они есть. Без них доступно ручное заполнение с явным выбором фьючерса и вводом размера позиции.
- [x] После изменения значимых параметров относительно снимка последний успешный отчёт остаётся видимым с пометкой «Параметры изменены». Успешный запуск заменяет отчёт, а ошибка нового запуска не выдаёт старый отчёт за новый.
- [x] Браузерный сценарий проверяет переход без сохранения, перенос черновика, ручной запуск, отображение отчёта и пометку после изменения формы. Прямой вход и обновление проверяются на том же уровне.

## Comments

Кнопка «Бэктест» в карточке стратегии передаёт черновик через in-memory history state роутера (`backtestDraft`), не сохраняя настройки и не помещая значения в URL. Страница `/backtest` переведена на контролируемую форму: черновик подставляется однократно, при прямом входе или обновлении без черновика поля заполняются из последних сохранённых настроек. Последний успешный отчёт хранится отдельно от текущего запроса, поэтому ошибка нового запуска не заменяет его, а при расхождении формы со снимком отчёта показывается пометка «Параметры изменены». Сценарий Playwright покрывает переход без сохранения, перенос черновика, запуск, отчёт, пометку и прямой вход с сохранёнными параметрами.
