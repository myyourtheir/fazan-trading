# 05: Расширить предел периода бэктеста

Status: done

**Что сделать:** Увеличить максимальный диапазон бэктеста с семи до тридцати календарных дней, опираясь на подтверждённые лимиты T-Invest API.

**Спецификация:** [Бэктест стратегии «Сёрфинг»](../spec.md).

## Критерии приёмки

- [x] Предел периода увеличен до 30 календарных дней; сервер применяет его одинаково и отдаёт через `GET /api/backtest/limits`, а форма показывает то же значение.
- [x] Чанкование истории (порции по 6 дней со сшивкой стыков) не изменено: лимиты T-Invest API на один запрос (5 минут — неделя, 15/30 минут — 3 недели, 1 час — 3 месяца) покрываются с запасом, общий диапазон API не ограничивает.
- [x] Диапазон вне периода торгов выбранного контракта по-прежнему отклоняется (`BACKTEST_CONTRACT_PERIOD`); практический потолок — срок жизни контракта.
- [x] Тесты, фиксирующие предел (REST-тесты бекенда и e2e-моки фронтенда), обновлены на новое значение, включая граничный случай «31 включительный день».
- [x] README различает подтверждённое покрытие (7 дней, `IMOEXF`) и новый предел (30 дней) и указывает, как подтвердить полный диапазон.

## Comments

Лимит `backtestLimits.maxDays` в `backend/src/core/backtest-history.ts` увеличен с 7 до 30. Ограничение не связано с API Т-Инвестиций: GetCandles ограничивает только период одного запроса (5 минут — неделя, 15/30 минут — 3 недели, 1 час — 3 месяца), а более длинная история получается поочерёдными запросами — это уже делает `gather` порциями по 6 дней со сшивкой стыков; GetTechAnalysis документированного лимита глубины не имеет, а дрейф EMA на стыках учтён допуском `closeEnough`. Сервис котировок допускает 600 unary-запросов в минуту: прогон 30 дней плюс 7-дневный бейзлайн — это около 7 чанков и 14 запросов, с большим запасом. Подтверждение покрытия полного 30-дневного предела требует запуска живой проверки песочницы с токеном (`node --import tsx --test src/infra/invest-sandbox.backtest.test.ts` из `backend/`): проверка берёт диапазон из `backtestLimits.maxDays` автоматически и прогоняет все поддерживаемые таймфреймы и периоды EMA.
