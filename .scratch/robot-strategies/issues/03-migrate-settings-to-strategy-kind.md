# 03: Перенести настройки на тип стратегии

**Что сделать:** Сохранить существующую конфигурацию «Сёрфинга» при переходе на дискриминируемые настройки стратегий, чтобы текущие пользователи могли продолжить работу без ручного переноса.

**Блокируется:** [02 — Ввести декларативный контракт стратегии](02-declare-strategy-contract.md).

**Статус:** ready-for-agent

- [ ] Настройки включают `kind` стратегии и её параметры, сохраняя текущие поля выбора инструмента и таймфрейма.
- [ ] Миграция Drizzle переносит прежние EMA-период и размер позиции в параметры `surfing` без изменения значений; миграция и метаданные поставляются вместе.
- [ ] Старые запросы без `kind` трактуются как «Сёрфинг», неизвестный явный `kind` отклоняется, отсутствие настроек не подменяется значениями по умолчанию.
- [ ] Чтение и запись валидируют параметры выбранной стратегии; повреждённые или неизвестные настройки не разрешают запуск робота.
- [ ] Существующий торговый журнал читается без миграции, его дедупликация и сверка ранее зарезервированных заявок сохраняются.
- [ ] Проверены пустая и прежняя схемы базы данных, включая точное восстановление старой конфигурации.
