# 03: Продолжать минутный бэктест при разрывах внутри диапазона

**Что сделать:** В явных вариантах «Сёрфинга» и «Улучшенного сёрфинга» недоступный или неподтверждённый минутными свечами интервал не срывает весь прогон, если осталась пригодная история. Владелец видит, какие интервалы исключены, а отчёт не моделирует исполнения внутри них.

**Блокеры:** 02 — считать по доступным границам и объяснять отсутствие результата.

Status: done

- [x] Если свеча стратегии не подтверждается минутами, отсутствует при наличии минут или её OHLC расходится с минутной агрегацией, интервал исключается. Проверка истории и запуск сообщают об исключениях, а отчёт показывает предупреждение, даже если фактические границы не изменились.
- [x] Если доступные минуты воспроизводят OHLC свечи стратегии, интервал остаётся пригодным. Сохраняются оговорка об оценочных сессиях и счётчик минут без свечей внутри них. Молчание обоих источников не выдаётся за доказанный пропуск, а цены не подставляются.
- [x] Обычный сигнал не переносится через разрыв. Защита уже открытой позиции в «Улучшенном сёрфинге» может сработать по первой подтверждённой цене после разрыва по действующим правилам гэпа. Внутри самого разрыва исполнений нет.
- [x] Если подтверждённых интервалов не осталось, показана причина без нового отчёта. Старый вариант без `kind` не получает зависимости от минутных свечей.
- [x] Тесты на публичной границе различают расхождение свечей, общую паузу и разрешённые минутные пропуски, а также проверяют обычный сигнал и защиту после разрыва.
