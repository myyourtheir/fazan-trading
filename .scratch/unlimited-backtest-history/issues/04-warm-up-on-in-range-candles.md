# 04: Прогревать индикаторы внутри запрошенного диапазона

**Что сделать:** Если пригодной предыстории недостаточно, владелец всё равно может получить результат: обязательные индикаторы продолжают прогреваться на первых пригодных свечах запрошенного диапазона. Отчёт показывает, с какого момента стратегия была готова торговать.

**Блокеры:** 02 — считать по доступным границам и объяснять отсутствие результата.

Status: done

- [x] Проверка истории и запуск используют пригодную предысторию по действующим правилам поиска и при необходимости продолжают прогрев внутри диапазона, не уменьшая заданные периоды EMA или ATR.
- [x] Сделок нет до готовности всех обязательных индикаторов, включая случай, когда ATR готов позже EMA. Свечи внутреннего прогрева входят в фактический диапазон, а граница готовности показана отдельно рядом с результатом. Даты формы не меняются.
- [x] Если до конца истории индикаторы не готовы, показана причина без нового торгового результата. Если индикаторы готовы, но сделок нет, возвращается обычный отчёт с нулём исполнений.
- [x] Публичные REST-тесты покрывают внутренний прогрев, отсутствие сделок до готовности, недостаточную историю и успешный прогон без сделок. Браузерная проверка подтверждает, что граница готовности видна рядом с отчётом.
