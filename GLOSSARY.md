# Торговые стратегии

Термины исторической проверки торговых стратегий.

## Язык

**Запрошенный диапазон**:
Календарные даты, которые пользователь выбрал для бэктеста, включая обе границы.

**Фактический диапазон**:
Период от первой до последней свечи, использованной для прогона внутри запрошенного диапазона. Его границы не означают, что все данные внутри периода доступны.

**Частичная история**:
История, в которой есть пригодные для бэктеста свечи, но известно, что они не покрывают часть запрошенного диапазона.

**Прогрев индикатора**:
Начальный отрезок истории, необходимый для получения первого пригодного для стратегии значения индикатора. Пока обязательные индикаторы не готовы, стратегия не торгует.
