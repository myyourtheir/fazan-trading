# Трекер задач: Local Markdown

Задачи и спецификации проекта хранятся в Markdown-файлах под `.scratch/`. Внешний трекер не используется.

## Соглашения

- Для каждой фичи — отдельная директория `.scratch/<feature-slug>/`.
- Спецификация: `.scratch/<feature-slug>/spec.md`.
- Задачи реализации: отдельные файлы `.scratch/<feature-slug>/issues/<NN>-<slug>.md`. Нумерация начинается с `01`.
- Статус указывается строкой `Status:` в начале документа. Если скилл предписывает статус, например `ready-for-agent`, записывай его в этой строке.
- Комментарии добавляются в конец файла в раздел `## Comments`.

## Работа с трекером

- «Опубликовать» — создать Markdown-файл по указанному выше пути, при необходимости создав директорию.
- «Прочитать задачу» — открыть соответствующий файл. Если указан номер, ищи его в `issues/` соответствующей фичи.
