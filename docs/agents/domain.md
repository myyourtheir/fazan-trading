# Доменные документы

Проект использует один доменный контекст. Перед изучением кода прочитай корневой `GLOSSARY.md` и ADR из `docs/adr/`, которые относятся к задаче. Если этих документов ещё нет, продолжай работу без них.

В спецификациях, задачах, тестах и предложениях по изменению кода используй термины из глоссария. Если нужного понятия там нет, не выдавай новый термин за согласованный.

Если предложение противоречит действующей ADR, явно укажи, какой записи оно противоречит и почему решение стоит пересмотреть. Не переопределяй ADR молча.
